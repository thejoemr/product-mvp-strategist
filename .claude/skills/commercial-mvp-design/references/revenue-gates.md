# Puertas de valor y monetización

La reducción que ahorra desarrollo pero destruye compra NO es optimización.

## Puertas de continuidad

- **G1 Problema**: hay un segmento definido y problema frecuente/costoso, respaldado o explícitamente hipotético.
- **G2 Resultado**: el cliente logra una salida comprobable sin depender de las features postergadas.
- **G3 Acceso/confianza**: el producto permite entrada, permisos, privacidad, condiciones y operación responsable.
- **G4 Cobro**: existe mecanismo de pago/facturación/manual o automatizado compatible con el segmento; no obligar a construir billing complejo para los primeros 3 clientes B2B si facturar manualmente es viable y legal.
- **G5 Sostenibilidad**: costo variable razonable, cumplimiento, soporte factible y una estrategia de retención si hay suscripción.
- **G6 Aprendizaje**: métricas/experimentos suficientes para decidir inversión, sin imponer analítica exhaustiva innecesaria.

## Reglas de prioridades

`P0`: preserva núcleo, seguridad/cobro, desbloquea primer valor o corta un costo prohibitivo.

`P1`: simplificación de alta fricción y demanda bien respaldada; se puede ejecutar tras asegurar P0.

`P2`: optimización atractiva pero no bloqueante, baja evidencia o riesgo importante; validación antes de ejecutar.

Ante mercado no probado, el plan puede recomendar un **MVP de validación comercial** antes de recortar irreversiblemente o construir más. Siempre separa `cambio funcional recomendado` de `evidencia pendiente`.
